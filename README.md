# CUL Foods

A clean, modern landing page for CUL Foods — a campus-focused food delivery hub. This project is built as a portfolio website demonstrating responsive layout, fixed header navigation, featured meal cards, an About section, and a working contact form interaction.

## Features

- Responsive full-width header section with hero messaging
- Fixed navigation bar that changes style on scroll
- Smooth section links for Home, About Us, Menu, Sign In, and Contact Us
- Featured meals grid with meal cards and pricing
- About Us section with brand messaging
- Contact Us section with form validation and success feedback
- Mobile-friendly layout with CSS adjustments for smaller screens

## Built With

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` — main page structure and content
- `styles.css` — desktop and global styling
- `mobile.css` — mobile-specific styles and layout tweaks
- `script.js` — smooth navigation behavior, mobile menu handling, and contact form validation
- `assets/` — image and icon assets used on the page

## Usage

1. Open `index.html` in a browser.
2. Scroll the page to see the header and navigation behavior.
3. Use the navigation links to jump to each section.
4. Fill out the contact form in the Contact Us section and submit to see validation and feedback.

## Notes

- The contact form is currently handled on the client side only. It displays a confirmation message and clears the form, but it does not send email or store data on a backend.
- This project is ideal for showcasing a polished static site and front-end interaction for a portfolio.
